## Como manter esta memória

- Registrar somente fatos confirmados e decisões aprovadas.
- Distinguir claramente `concluído`, `em validação`, `pendente` e `proposta`.
- Ao corrigir uma falha, registrar causa, impacto, evidência e barreira preventiva.
- Não registrar credenciais, chaves, URLs com token nem lançamentos financeiros individuais.
- Atualizar o roadmap e esta pasta no mesmo trabalho quando uma etapa mudar de estado.
